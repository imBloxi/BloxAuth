CACHE SYSTEM IMPLEMENTATION
================================================================================

Cache Helper Functions:
- get_cache($key) - Retrieve cached data
- set_cache($key, $value, $ttl) - Store data with TTL
- clear_cache($key) - Invalidate cache
- clear_license_cache($license_id) - Clear license-specific cache
- init_cache() - Initialize cache system
- get_cache_file($key) - File-based cache retrieval
- set_cache_file($key, $value, $ttl) - File-based cache storage
- clear_cache_file($key) - File-based cache clearing
- get_cache_redis($key) - Redis cache retrieval
- set_cache_redis($key, $value, $ttl) - Redis cache storage
- clear_cache_redis($key) - Redis cache clearing
- get_redis_connection() - Redis connection manager

Cache Providers:
- File-based (default): No dependencies, stores in /tmp/bloxauth_cache
- Redis (optional): High-performance, recommended for production

Cached Data Types:
- License Types: 1 hour TTL (rarely changes)
- User Data: 15 minutes TTL (moderately dynamic)
- License Validation: 10 minutes TTL (frequently accessed)
- User Permissions: 30 minutes TTL (security-related)
- Config Values: 1 hour TTL (rarely changes)

Cache Invalidation:
- Automatic on license create/update/revoke
- Manual via clear_cache() functions
- TTL-based expiration
